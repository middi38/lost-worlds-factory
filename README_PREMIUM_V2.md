# Lost Worlds Factory — Premium V2
Mobile-first GitHub Actions video factory for vertical historical Shorts.

## Run
Actions → Premium Video Factory → Run workflow → enter the JSON name (for example `doggerland`).

## Premium V2
- Kokoro narration with Edge TTS fallback
- cinematic vertical AI-image prompts
- per-scene Ken Burns motion
- voice loudness processing
- high-contrast timed subtitles and opening hook
- optional background music mixing
- metadata artifact
- input validation and retry/fallback behavior
- `used_topics.json` starter list for duplicate-topic tracking

Keep `POLLINATIONS_TOKEN` only in GitHub Actions Secrets. Never commit API keys.
